\# MovieMind — Personalized Recommendation Engine



A machine-learning based movie recommendation system built with Python, Scikit-learn, FastAPI, and a simple web frontend.



\## Features



\- Content-based movie recommendations

\- Collaborative filtering

\- Hybrid recommendation engine

\- FastAPI REST API

\- Interactive web frontend

\- MovieLens dataset

\- No paid APIs required



\## Architecture
